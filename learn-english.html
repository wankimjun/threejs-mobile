Đồng bộ tiến độ

Tiến độ luôn được lưu trên trình duyệt. Nếu điền thông tin GitHub bên dưới, nút Lưu lên repo sẽ ghi file data/progress.json trong repo của bạn. Trang GitHub Pages cập nhật sau vài phút.
Cài đặt GitHub
Token có quyền ghi vào repo của bạn, nên chỉ cấp quyền cho đúng repo này và chỉ quyền Contents. Không dán token vào mã nguồn hay commit nó vào repo. Nếu repo công khai, nội dung data/progress.json cũng công khai.
